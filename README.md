# Hello CS321

Read a name from standard input and print:

```
Hello, <name>, welcome to CS321 class.
```

## Build
```bash
make
```

## Run (examples)
```bash
echo "Nawaz" | ./hello
# Hello, Nawaz, welcome to CS321 class.
```

## What's graded
- Compiles with `make`
- Exact output format (including commas, spaces, period, newline)
